# Research skill

When asked to look something up (facts, code, web data):
1. Search first (`web_search`), then fetch promising URLs (`fetch_web`)
   for detail. For library docs, prefer `context7` when it covers the repo.
2. Cross-check numbers from two independent sources when they matter.
3. State the source URL alongside any fetched claim.
4. If a tool is denied by the sandbox, say so and give what you know.
