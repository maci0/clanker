# Research skill

When asked to look something up (facts, code, web data, library docs):
1. Search first (`web_search`), then fetch promising URLs (`web_fetch`)
   for detail. For third-party library docs, use `context7` with `{org, repo,
   topic?}` (GitHub org/repo names, not this checkout's tree).
2. Cross-check numbers from two independent sources when they matter.
3. State the source URL alongside any fetched claim.
4. If a tool is denied by the sandbox, say so and give what you know.
